# MOI

奶白与淡紫色的 SillyTavern 界面扩展。包含小物导航栏、可折叠的硫酸纸会话栏、角色文件夹首页、相片打印机、纸团留言和掌机音乐播放器。

## 安装

1. 在酒馆打开 **扩展程序 → 安装扩展**，粘贴：
   ```text
   https://github.com/Hhhayato621/MOI-layout
   ```
2. 安装完成后刷新酒馆。
3. 在扩展设置中找到 **MOI · 奶白频道**，点击 **下载 MOI 侧边栏版** 或 **下载 MOI 顶部栏版**。
4. 打开 **用户设置 → UI 主题 → 导入主题**，选择对应的主题 JSON，再选择 **MOI · 侧边栏版** 或 **MOI · 顶部栏版**。
5. 可选：回到 MOI 扩展设置，点击 **导入本机字体**，选择自己下载并有权使用的 TTF / OTF / WOFF 字体文件。

也可以直接在本仓库下载 [MOI-theme.json](./MOI-theme.json)，然后导入主题；顶部栏版见 [MOI-顶部栏版.json](./MOI-顶部栏版.json)。

主题用于启用布局和配色，扩展提供交互与素材，两者需要一起使用。切回其他主题会隐藏 MOI 界面。

## 使用

- 左侧小物图标对应酒馆原有设置。回形针展开或收起最近会话。
- 首页文件夹读取当前账号的角色和聊天存档，按最近聊天顺序排列；点击文件夹后可选择存档。
- 右侧箭头展开或收起组件栏。点击相纸可选择角色、更换照片和打印；相纸下的文字可编辑。
- 点击纸团展开留言，点击纸条揉回。随机选择至少有一个存档包含 3 条非系统消息的角色，使用其最新合格存档的最近 3 条消息生成留言。需要连接模型，会产生模型请求及相应费用。
- 掌机十字键中央 **＋** 打开音乐列表，可导入本机音频或粘贴音频链接。两颗圆键切歌，小三角键播放或暂停，点击屏幕也能打开歌单。
- 歌单中点击 **✎** 修改歌名。十字键左右快退/快进，上下调整音量。

## 音乐链接说明

支持浏览器能够播放的音频直链，以及网易云的完整单曲链接。会员限制、来源防盗链、网络及地区限制、音频格式或浏览器跨域限制都可能造成加载失败；本扩展不提供破解、付费内容解锁或万能格式转换。

`163cn.tv` 短链接不保证能够自动展开；失败时先在浏览器打开短链接，再复制地址栏中的完整单曲网址。iPhone 需要手动点击播放。iOS 对网页音量和后台播放的支持由系统决定。

音乐与自选照片保存在当前浏览器或 App 的本地存储中，不会随扩展仓库分发，也不会自动同步到另一台设备。清除站点数据或 App 数据可能清除这些内容。

## 字体

设计时使用「鸿雷小纸条青春体」。其原附声明限制字体文件的第三方传播，因此仓库不附带此字体，也不附带其他替代字体。请从作者授权渠道自行取得，再用扩展的「导入本机字体」功能应用；未导入时使用设备的备用字体。

## 兼容性

- 已在 SillyTavern 1.19.0 的本地网页环境验证主要功能。
- 使用 SillyTavern 前端扩展结构，根目录包含 `manifest.json`，不需要安装服务端插件。
- TauriTavern 需要其版本支持通过 GitHub 安装前端扩展；尚未在真实 iPhone / TauriTavern 中逐项验证。不保证所有分支或旧版本的内部接口完全相同。
- 需要关闭重复安装的旧 After Hours / MOI 布局扩展，避免出现两套界面。
- 仓库没有替换启动载入动画，也不包含之前的复古打字机主题。

## 数据使用

扩展读取当前酒馆账号的角色与聊天列表以展示首页、导航和纸团留言。纸团生成时，把用于生成的最近 3 条消息通过你已配置的酒馆模型连接发送给对应模型服务。本扩展没有额外的聊天上传服务器。

导入在线音乐时会访问该音频来源；本机字体、自选照片和本机音频不上传到 GitHub。仓库不包含任何人的角色卡、头像、聊天存档、API 密钥或私人歌单。

## 两个版本

- **MOI · 侧边栏版**：保留左侧小物导航栏。
- **MOI · 顶部栏版**：小物导航改在顶部，适合手机；设置面板、回形针、右侧组件随之避让顶栏。

两个版本共用同一个扩展，只需切换 UI 主题，不要重复安装扩展。

## 手机性能调整

手机触控设备使用半透明材质代替叠加实时模糊，减少首页多文件夹和大面积侧栏的重绘；纸团改为短的二维展开效果；证件牌只更新发生变化的消息；音乐播放避免反复重写没有变化的文字。手机证件牌已放大，下方按钮图标缩小并保留点击范围。

这些调整已在网页的 390 × 844 视口检查布局，未在真实 iPhone 上测量帧率；不同聊天内容、嵌入页面和其他扩展仍会影响流畅度。
